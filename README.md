## 🚀 Featured Projects

### 1. **Gocals** 📍[Live Link](https://gocals.com)
> **AI-Powered Local Events Platform** &middot; *Backend & AI Automation Intern (Kverty)*
- **Core Stack:** Go (Gin), PostgreSQL, Redis, PostGIS, LangChain, LangGraph.
- **Architectural Highlights:**
  - Engineered scalable backend microservices managing event registration, authentication, admin workflows, and geographic discovery.
  - Architected AI automation pipelines leveraging LangChain and LangGraph for automated event content ingestion, data extraction, and decision workflows.
  - Implemented structured logging, validation layers, database optimizations (PostGIS), and production-grade error handling.

### 2. **MetaCopilot** 🤖
> **Conversational AI Layer for OpenMetadata** &middot; *Multi-Tenant SaaS Platform* &middot; [GitHub Repo](https://github.com/arbaznova/MetaCopilot-main)
- **Core Stack:** Go (Gin), React, PostgreSQL, Supabase, LangChain, LangGraph, OpenMetadata REST APIs.
- **Architectural Highlights:**
  - Designed a secure multi-tenant dashboard allowing users to query metadata catalogs via natural language.
  - Leveraged LangChain/LangGraph and Google Gemini to map user questions to exact API schemas, lineage data, and tables dynamically.
  - Handled secure connection isolation via bot JWT tokens without saving credential data on external services.

### 3. **Whisperly Chat Server & AI Bridge** 🔒
> **Secure Real-time Chat Engine & LLM Broker** &middot; *Built From Scratch* &middot; [GitHub Repo](https://github.com/arbaznova/Whisperly)
- **Core Stack:** Java, Concurrency (Thread Pools, Lock-Free Registries), TLS, X.509 PKI, Python, FastAPI, LLM APIs.
- **Architectural Highlights:**
  - **The Server:** Custom TCP socket-based server engineered with a custom application-layer routing protocol, lock-free registries for thread-safe users/sessions, and backpressure handling.
  - **The Security:** Implemented TLS-secured client-server messaging backed by an X.509 Certificate authority.
  - **The AI Bridge:** Language-agnostic FastAPI broker providing session-aware conversation context memory and prompt orchestration to plug in any LLM service.
